# Library Management Website

## Description
This project is a simple Library Management Website developed using HTML, CSS, and JavaScript.  
It allows users to manage books easily through a clean and interactive interface.

## Features
- Add new books
- Display all books
- Search books by title
- Delete books
- Store data using Local Storage

## Technologies Used
- HTML
- CSS
- JavaScript
